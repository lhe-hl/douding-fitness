## 一、 视觉设计与设计稿对齐

根据最新原型图，首页确立以下视觉规范与色彩体系：

### 1.1 页面色彩体系
- **全局背景色**：`#F7F8FA`（柔和低饱和灰白，护眼且凸显白色卡片）。
- **主功能色（活力绿）**：`#74C043` / `#67C23A`（用于运动能量环、健身打卡进度柱、蛋白质健康进度条）。
- **活力强调色（能量橙）**：`#FF8E29`（用于连续打卡徽章火焰、热量环重点弧段、碳水脂肪进度条）。
- **微光卡片色（AI 助理）**：渐变浅青绿玻璃拟态背景（`linear-gradient(135deg, #E6F9F3 0%, #D4F4EA 100%)`）。
- **文本颜色**：
  - 主标题/大数值：`#1A1A1A`（加粗加大）。
  - 副标题/辅助说明：`#8C8C8C`。
- **卡片样式**：纯白底色（`#FFFFFF`），超大圆角 `border-radius: 28rpx`，轻微弥散柔和阴影 `box-shadow: 0 8rpx 24rpx rgba(0, 0, 0, 0.04)`。

## 二、 前端架构与组件拆分规范

遵循 **“就近原则（Colocation）”** 与 **“容器/展示组件解耦”** 原则，将首页代码组织在 `client/src/pages/index/` 下：

```text
client/src/pages/index/
├── components/                      # 首页专属子组件库
│   ├── HomeHeader.vue               # 1. 顶部用户状态栏 (问候语 + 连续打卡胶囊)
│   ├── WorkoutCard.vue              # 2. 健身模块卡片 (本周已练 + 7天柱状图 + 运动能量环 + 标签)
│   ├── DietCard.vue                 # 3. 饮食模块卡片 (热量刻度环 + 宏量营养素条 + 快速添加入口)
│   └── AiCoachCard.vue              # 4. AI 教练模块 (拟物机器人 + 诊断气泡 + 咨询按钮)
├── types.ts                         # 首页专用 TypeScript 类型契约
└── index.vue                        # 首页父容器 (负责数据聚合加载、下拉刷新、统一分发)
```

## 三、 各组件详细设计与接口契约 (Props & Emits)

### 3.1 顶部栏：`HomeHeader.vue`
* **视觉要素**：
  - 左侧：圆形头像（48px）、当前动态问候语（根据当前时间判定“早上好 / 下午好 / 晚上好”）、日期文本（如“9月23日 星期三”）。
  - 右侧：橙色渐变圆角胶囊：“🔥 连续打卡5天”。
* **Props 契约**：
  ```typescript
  interface HeaderProps {
    avatarUrl?: string;
    greeting?: string;      // 默认自动根据时段计算
    dateStr?: string;       // 格式: M月D日 星期X
    streakDays: number;     // 连续打卡天数
    isLoggedIn: boolean;    // 是否已登录
  }
  ```
* **Emits 事件**：
  - `@click-avatar`：点击头像（未登录触发一键微信登录，已登录进入个人中心）。
  - `@click-streak`：点击打卡徽章（弹出打卡成就轻提示）。

---

### 3.2 健身卡片：`WorkoutCard.vue`
* **视觉要素**：
  - 标题行：左侧“本周已练 4 次”，右侧带箭头的“运动能量 ❯”。
  - 中间图表区：
    - 左侧：周一至周日 7 天立柱进度图（已完成的天数使用活力绿填充并附带胶囊高亮，未完成为浅灰色）。
    - 右侧：纯正“运动能量”环形进度条（百分比环，居中展示“运动能量”或百分比数字）。
  - 底部标签区：弹性流式标签（“胸肩塑形”、“有氧燃脂”等灰色圆角标签）。
* **Props 契约**：
  ```typescript
  interface WorkoutCardProps {
    weekCount: number;                 // 本周练了多少次，如 4
    dailyStatus: {                     // 周一到周日打卡状态
      dayLabel: string;                // "周一", "周二"...
      completed: boolean;              // 是否完成
      intensity: number;               // 柱状高度比例 0~100
    }[];
    energyPercent: number;             // 运动能量完成度 0~100
    focusTags: string[];               // 焦点标签列表，如 ["胸肩塑形", "有氧燃脂"]
  }
  ```
* **Emits 事件**：
  - `@click-detail`：点击卡片或“运动能量 ❯”，跳转至健身记录页面。

---

### 3.3 饮食和热量卡片：`DietCard.vue`
* **视觉要素**：
  - 标题行：“饮食和热量”，右侧带跳转箭头“❯”。
  - 左侧热量环：
    - 大刻度半开环进度条（绿/橙渐变色）。
    - 环内文字：居中显眼数值“1450”，下行小字“/ 1800 kcal”。
    - 环下方状态胶囊：“🔥 热量缺口状态”。
  - 右侧营养素与快捷添加：
    - 宏量营养素条：蛋白质（绿色条，标示目标）、碳糖质（橙色条）、脂肪（橙红条）。
    - 快速添加按钮组：“早餐”、“午餐”、“晚餐”（已记录为高亮绿色，未记录为淡灰按键）。
* **Props 契约**：
  ```typescript
  interface DietCardProps {
    currentCalories: number;           // 今日已摄入，如 1450
    targetCalories: number;            // 今日目标热量，如 1800
    deficitText: string;               // 缺口提示文字，如 "热量缺口状态"
    macros: {
      protein: { current: number; target: number; percent: number };
      carbs: { current: number; target: number; percent: number };
      fat: { current: number; target: number; percent: number };
    };
    mealsStatus: {                     // 早中晚记录状态
      breakfast: boolean;
      lunch: boolean;
      dinner: boolean;
    };
  }
  ```
* **Emits 事件**：
  - `@click-detail`：点击卡片跳转到饮食记录页。
  - `@quick-add`：点击早餐/午餐/晚餐（例如 `@quick-add="breakfast"`），唤起快速录入弹窗。

---

### 3.4 AI 教练卡片：`AiCoachCard.vue`
* **视觉要素**：
  - 背景：清爽的青绿微光渐变圆角容器。
  - 标题行：“AI 教练”，右侧带“❯”。
  - 内容区：
    - 左侧：立体可爱的绿色机器人头像/小挂件。
    - 右侧：白色气泡对话框：“今日热量缺口合理！晚餐建议适量增加蛋白质”。
  - 右下角：高对比度纯黑胶囊按钮：“咨询 AI 教练”。
* **Props 契约**：
  ```typescript
  interface AiCoachCardProps {
    adviceSummary: string;             // AI 核心建议文本
    isAnalyzing?: boolean;             // 是否正在分析中
  }
  ```
* **Emits 事件**：
  - `@ask-coach`：点击“咨询 AI 教练”或气泡，无缝平滑切换到底部第 4 个 Tab（AI 助手界面）。

## 四、 后端聚合接口设计 (API 契约)

* **请求方式**：`GET /api/home/overview`
* **鉴权要求**：Header 携带 `Authorization: Bearer <token>`（未登录则返回基础默认 Mock 数据）
* **响应数据结构 (JSON)**：

## 五、 交互行为与页面跳转链路

| 触发位置 | 触发操作 | 目标动作 / 页面路由 |
| :--- | :--- | :--- |
| **顶部头像/昵称** | 点击 | 若未登录唤起静默登录；若已登录切换至 `pages/profile/index` |
| **打卡天数胶囊** | 点击 | 触发轻量 Toast: "已连续自律 5 天，太棒了！" |
| **健身卡片 / 箭头** | 点击 | `uni.switchTab({ url: '/pages/workout/index' })` 跳转到健身打卡页 |
| **饮食卡片 / 箭头** | 点击 | `uni.switchTab({ url: '/pages/diet/index' })` 跳转到饮食记录页 |
| **快速添加 (早/中/晚餐)** | 点击按钮 | 打开半屏快速录入抽屉，填入食物与估算热量后原地刷新数据 |
| **AI 咨询按钮** | 点击 | `uni.switchTab({ url: '/pages/ai-coach/index' })` 跳转至 AI 问答页 |

## 六、 分步实施与验收里程碑

### 阶段 1：静态样式高保真还原（当前计划重点）
1. 在 `client/src/pages/index/components/` 建立 4 个空组件文件。
2. 采用标准 CSS / SCSS 还原设计稿上的卡片圆角、阴影、圆环与柱状图布局。
3. 注入本地 Mock 数据，确保在微信开发者工具中看到的界面与最新原型图达到 95% 以上一致度。

### 阶段 2：交互与动效打磨
1. 热量刻度环与能量环的 CSS 渐变与转角平滑度。
2. 快速添加入口轻触按压反馈。
3. 点击各模块与底部 TabBar 之间的平滑跳转。

### 阶段 3：后端聚合接口联调
1. 在 `server` 编写 `GET /api/home/overview` 控制器与服务层逻辑。
2. 前端封装 `api/home.ts` 发起请求，将真实数据库数据灌入页面。
